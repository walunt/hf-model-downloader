# HuggingFace 模型下载器

基于 `hfd.sh + aria2` 的本地大模型高速下载工具，带可视化网页控制台，支持 hf-mirror 国内镜像 / 官方直连一键切换、并发调节、**下载限速**、断点续传、**失败自动重试（最多 4 次，指数退避）**、自动 sha256 校验、完成通知、**队列全部完成通知**、历史任务续传、任务队列自动接力、30 分钟速度曲线、**下载中磁盘实时预检（不足自动暂停）**、**模型库校验状态一览**、**模型库一键删除（移入废纸篓可恢复 / 彻底删除）**、**下载任务可移除（可选连本地目录一起删）**、**任务卡片/列表双视图**、**移动端适配（iPhone 竖屏）**、**添加到主屏幕（PWA）**、**任务与模型库批量操作**、**局域网访问口令**、**已完成任务折叠**、**失效记录清理**、**元数据补全**、**主日志/模型日志切换**、开机自启与崩溃自愈。

> 当前版本 **v3.41 · 本系统由核桃制作**｜版本规则：**大版本号仅在有重大更新或明确要求时递增；小版本号 = 累计更改次数（本次为第 41 次），每次调整 +0.1**

## 启动方式

- **方式一（推荐，开机自启 + 崩溃自动重启）**：双击 `安装开机守护.command` 一次即可。它会把运行时部署到 `~/Library/Application Support/hf-model-downloader/` 并注册 macOS LaunchAgent，之后登录自动启动、进程崩溃 5 秒内自动拉起；配合「重启自动续传」实现断网/重启后无人值守续传。卸载双击 `卸载开机守护.command`。
  - 为什么要部署到 Application Support：`~/Desktop` 受 macOS 隐私（TCC）保护，launchd 后台进程无权读取会报 `Operation not permitted`；桌面目录保留为**源码**，改完代码重新双击安装脚本即同步。
- **方式二（临时手动）**：双击 `启动下载器.command`，自动启动并打开浏览器（若守护已在运行则直接打开页面）
- **方式三（终端）**：
  ```bash
  cd /path/to/hf-model-downloader
  python3 progress_server.py
  ```
  然后浏览器打开 http://localhost:8765 （https 同端口也可，自签名证书点继续即可）

## 使用流程

1. 在「① 新建下载」粘贴 HuggingFace 地址或 `组织/模型名`，gated/私有仓库在下方密码框填入 HF Token（read 权限，自动安全保存，不回显）
2. 点「分析」查看总大小、文件数、保存路径，可调整并发（分析成功后输入框自动清空，方便粘贴下一个链接；失败则保留便于修改）
3. 点「开始下载」；「③ 下载控制台」可随时切换镜像/直连、调并发、暂停/继续
   - 任务卡片右下角有「删除任务」，三选一：**仅移除任务**（文件保留，可从「最近任务」续传）/ **移到废纸篓**（连模型目录一起，秒级可恢复）/ **彻底删除**（连模型目录一起抹除，不可恢复）
   - 任务正在下载时也能删，会先按进程组停掉下载再处理目录；释放的并发名额自动让给队列
   - 标题右侧有「批量」开关：开启后每张卡片/每一行出现勾选框，可「全选 / 全部暂停 / 全部继续 / 批量删除」；批量删除同样支持 仅移除任务 / 移到废纸篓 / 彻底删除，单个失败不影响其余（会提示跳过几个）
4. 默认保存根目录在「④ 默认设置」里改，模型存到 `根目录/组织/模型名`，默认 `~/mlx-models`
5. 想一次排多个模型：分析后点「加入队列」（成功有顶部浮层提示，队列面板在「新建下载」正下方），当前任务完成并校验通过后会自动接力下一个（「下载队列」可移除/清空）
6. 已完成的任务默认折叠成三行紧凑卡片（模型名 / 绿色进度条 / 体积与完成时间），点「展开」看完整信息，展开状态会记住；进度条按状态分色：已完成绿、下载中蓝、已暂停灰、校验中青、失败红
7. 当前任务区有最近 30 分钟速度曲线、当前/均值/峰值速度与目标盘剩余空间；页面切到后台时自动降频省资源
8. 标题栏右侧可切换**浅色 / 深色主题**，选择会记住；「本地模型库」标题有搜索框，输入即过滤（只影响显示，删除等按钮仍指向正确模型）
9. 任务卡片有「打开目录」（折叠卡显示「打开」），一键在访达中打开模型所在文件夹；「下载队列」支持多选，可一次移除多个待下载任务
   - 「下载任务」标题右侧可切换 **卡片 / 列表** 两种视图：卡片看单个任务的细节（分片、进行中文件），列表是紧凑表格，一眼横比所有任务的状态/进度/速度/剩余/分片；选择记在本机浏览器里，下次打开沿用
7. 想清理磁盘：「本地模型库」每行右侧有「删除」，可选两个动作
   - **移到废纸篓**（推荐）：同卷 `rename`，百 GB 也是秒级，可在废纸篓里恢复，清空废纸篓后才真正释放空间
   - **彻底删除**：直接抹除、不可恢复，空间立即释放（会有二次确认）
   - 正在下载或在队列中的模型不允许删除；删除后对应的下载任务条目会自动清除（「最近任务」仍保留，可一键重新下载）
   - 「本地模型库」标题右侧也有「批量」：勾选多个模型后一次「移到废纸篓」或「彻底删除」
   - 「本地模型库」标题右侧的「补全元数据」：为缺少 `repo_metadata.json` 的老模型补拉一次文件清单（只请求元数据、不下载文件），补完「总量未知」变成真实大小，分片池分配也更准；上游查不到的本地自建目录会被标记为「本地目录」并不再重复请求
   - 「最近任务」里若某条记录对应的目录已被删除，会整行置灰 + 删除线 + 「目录已删除」标记，重新校验/打开目录置灰；标题右侧出现「清理失效记录」一键清掉这些死记录
   - 「下载队列」标题的「多选」：勾选后一次移除多个待下载任务（只删队列记录，不影响正在下载的）

## 添加到主屏幕（iPhone / 平板）

1. 在「默认设置 → 访问范围」切到 **允许局域网访问**，保存（默认是「仅本机」，手机连不上）
2. 记下页面提示的地址（形如 `http://192.168.1.13:8765`），确保 iPhone 与 Mac 在**同一 Wi-Fi**
3. iPhone Safari 打开该地址 → 点底部「分享」→「添加到主屏幕」
4. 之后从主屏幕图标启动，即为全屏模式（无地址栏），图标为蓝底白色托盘箭头

> 安全提示：开启局域网后，任何设备打开该地址都会先要求输入**访问口令**（在「默认设置 → 访问口令」里生成/查看；本机即这台 Mac 免口令）。公共/办公网络用完建议切回「仅本机」。

## 安全设计

| 项 | 做法 |
|---|---|
| HF Token | 不进命令行（`ps` 看不到）：写入 600 权限临时文件由 `hfd.sh` 读取，退出即删 |
| Token 落盘 | `hfd.sh` 生成的 `aria2c_urls.txt` 含鉴权头，创建即 `chmod 600`；`hf_download.sh` 退出（含失败）时抹掉 Authorization 行 |
| 局域网访问 | `lan` 开关（默认关）；关闭时非本机请求一律 403 |
| 访问口令 | `lan` 开启后可设口令；非本机请求必须带正确口令，错误口令延时 0.35s 拖慢暴力尝试；口令只在本机可见/可改 |
| CSRF | Host/Origin 白名单 = 本机回环 + 本机所有 IPv4，伪造 Host 返回 403 |
| 静态资源 | 仅暴露 `manifest.webmanifest` 与 `assets/`，`realpath` 前缀校验防路径穿越 |
| 防误入库 | `.gitignore` 屏蔽 `*.hfd/`、`aria2c_urls.txt`、`last_download_command`、模型权重与凭证文件 |
| 提交守卫 | `.githooks/pre-commit`（已启用）：暂存区出现 token/私钥形态或模型元数据即拒绝提交 |
> 图标资源在 `assets/`（`apple-touch-icon.png` 180×180 等），清单为 `manifest.webmanifest`。

## 仓库卫生

仓库为**公开**状态，因此设了两道防线防止凭证误入库：

1. `.gitignore` 兜底——`*.hfd/`（含 `aria2c_urls.txt`、`last_download_command`）、模型权重、`.huggingface/`、`.env`、`*.pem` 全部忽略。
   这一条很关键：`default_root` 允许改成任意路径，万一指到仓库内，模型目录也不会被 `git add -A` 带走。
2. `.githooks/pre-commit` 主动拦截——扫描暂存区新增行，命中 `hf_` / `ghp_` / `sk-` / `AKIA` / `Bearer` / 私钥块即拒绝提交，并对新增 `.py`、`.sh` 做语法检查。

换机或重新 clone 后需执行一次：`git config core.hooksPath .githooks`（本机已配置）。

## 文件说明

| 文件 | 作用 |
|---|---|
| `progress_server.py` | 本地后端服务（端口 8765，http/https 双协议，路径自动跟随脚本位置） |
| `dashboard.html` | 可视化界面 |
| `hfd.sh` | HuggingFace 高速下载器（第三方，aria2/wget 后端） |
| `hf_download.sh` | 通用下载+校验脚本，由后端按任务调用 |

| `dl_config.json` | 持久化配置（默认路径、当前任务、历史） |
| `download.log` | 下载主日志 |

> 守护模式的实际运行目录是 `~/Library/Application Support/hf-model-downloader/`（含其独立的 dl_config.json / server.log / download.log）；模型数据仍在 `~/mlx-models`。

## 备注

- aria2 的 `-x`（单文件线程）/`-j`（同时下载分片数）上限均为 10
- 中断后重跑/点继续即自动断点续传；全部下完会自动与 HF 官方 sha256 比对，结果写 `<模型目录>/.hfd/verify_result.json` 并在页面显示，同时发 macOS 通知
- 「最近任务」可一键重新打开/断点续传；服务重启后，上次处于运行态且未完成的任务会自动续传（主动暂停的不会）
- 「本地模型库」按最近活动时间倒序排列（最近下载/续传的在前），卡片标题显示总数；超过 200 个时提示仅显示最近 200 个，不会静默隐藏
- 控制台按钮按运行状态自动启用/禁用；日志支持「只看问题」过滤与「清空显示」；控制口仅接受本机来源请求（校验 Host/Origin，防其他网页 CSRF）
- 依赖：`brew install aria2 wget`；token 存于 `~/.huggingface/token`（权限 600）
- 移动端（≤640px）已适配：输入框 16px 字号（防 iOS 聚焦自动放大）、按钮触控区 ≥36px、列表视图自动转为堆叠块（不再横向滚动）、安全区留白 `env(safe-area-inset-*)`
